# Design system de 3DAltoque

Fecha: 17 de octubre de 2026. Versión: 1.1.

Identidad derivada del logo: azul profundo, cian y magenta, con tipografía Manrope y Space Grotesk. La biblioteca vincula las specs funcionales con sus controles, estados y patrones de composición.
