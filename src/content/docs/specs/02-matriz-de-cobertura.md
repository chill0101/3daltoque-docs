## 1. Resumen de cobertura del proyecto

| Dimensión trazada | Total de elementos | Cobertura hacia artefactos de diseño y prueba |
| --- | --- | --- |
| **Funcionalidades del proyecto** | `24` (`F01`–`F24`) | `24 / 24` vinculadas a `RF`, `CU`, pantallas y pruebas (`F04`, `F18`, `F21` priorizadas como evolutivas `P2/P3`) |
| **Requerimientos Funcionales vigentes** | `54` (`RF-01.1`–`RF-12.15`) | `54 / 54` vinculados a `CU`, pantallas `WEB`/`MOB`, tablas SQL y casos de prueba `CP` |
| **Requerimientos Funcionales retirados** | `9` (`RF-08.1`–`RF-08.9`) | `9 / 9` preservados como antecedente histórico y reemplazados por `RF-12.1`–`RF-12.15` (`ADR-002`) |
| **Requerimientos No Funcionales** | `19` (`RNF-01`–`RNF-19`) | `19 / 19` justificados en la arquitectura modular y vinculados a pruebas `PNF`/`CP` |
| **Casos de Uso** | `13` principales + `6` subcasos | `19 / 19` especificados con flujos normales, alternativos, criterios de aceptación y pruebas |
| **Vistas e inventario de prototipos** | `32` Web + `30` Mobile (`110` composiciones) | `100%` mapeadas a módulos de diseño y casos de uso |
| **Casos de Prueba diseñados** | `28` `CP` + `8` `PNF` (`36` totales) | Cubren el `100%` de los `54 RF` y `19 RNF` vigentes |
