# Prototipos de catálogo y conversaciones

Versión 1.0. Fecha: 1 de noviembre de 2026.

[Abrir el prototipo navegable](/3daltoque-docs/documentos/c38bd72b53be-catalogo-y-chat.html). El selector permite recorrer doce vistas Web y Mobile y sus estados de carga, vacío, error, versión modificada, sesión y acceso comercial. Los datos del prototipo son ejemplos de referencia.

## Recorridos

**Cliente:** perfil del maker → detalle del producto → cantidad y condiciones → confirmación → conversaciones del pedido.

**Maker:** mis productos → editor → guardar versión → publicar o pausar → consultar publicación. El formulario permite revisar precio, moneda, cantidades, plazo, configuración y medios.

**Conversación:** abrir un pedido confirmado → consultar historial → redactar y enviar mensaje. El acceso comercial vencido conserva los pedidos existentes.

## Comprobación de la referencia

Se verificaron las doce vistas sin errores de JavaScript ni desbordamiento horizontal. Se recorrieron alta/edición del producto, validación de cantidades, revisión de condiciones, confirmación, apertura de conversación y envío de mensaje. La consulta pública permanece disponible antes de ingresar.

Las composiciones anteriores y sus enlaces de Figma se conservan en el [inventario](/3daltoque-docs/specs/03-inventario-de-vistas-y-flujos/). Los campos, permisos y estados del producto se detallan en [F25](/3daltoque-docs/specs/f25-catalogo-de-productos-del-maker/) y [F13](/3daltoque-docs/specs/f13-mensajeria-cliente-maker/).
