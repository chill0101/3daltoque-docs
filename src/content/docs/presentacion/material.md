# Material de presentación

Versión 1.0. Fecha: 1 de noviembre de 2026.

## Presentación navegable

[Abrir las diez diapositivas](/3daltoque-docs/documentos/95b080382aea-presentacion.html). La presentación admite flechas del teclado, botones, acceso directo por número de diapositiva e impresión. Utiliza el logo y los colores del proyecto.

## Contenido y notas de exposición

### 1. 3DAltoque

Una plataforma para conectar clientes con makers por capacidad y ubicación. Lucas Bernardez · María del Rosario Cariaga · Lucas Ruiz

**Apoyo:** Presentar equipo y problema sin atribuir cifras a entrevistas pendientes.

### 2. Dos formas de empezar

Solicitud personalizada con STL y ofertas comparables. Catálogo del maker con configuración y precio fijos. Ambos recorridos continúan por el mismo pedido y su historial.

**Apoyo:** Abrir catálogo y solicitud; explicar la elección del cliente.

### 3. Un acuerdo que se puede seguir

Solicitud → ofertas → confirmación → producción → revisión → encuentro → recepción. La aprobación del resultado y la recepción son acciones expresas del cliente.

**Apoyo:** Relacionar los pasos con las condiciones que conserva el pedido.

### 4. La mesa de trabajo del maker

Perfil con impresoras y materiales. Portfolio autorizado. Productos a precio fijo. Invitaciones y ofertas. Cola de pedidos y evidencias. El chat se abre desde el pedido confirmado.

**Apoyo:** Mostrar las acciones del maker y su cola.

### 5. Un modelo de membresía

Renovación manual. Prueba general y programa Makers Fundadores con duración y cupo configurables. La impresión se paga directamente al maker según el acuerdo del pedido.

**Apoyo:** Mostrar duración, cupo y precio del entorno elegido; explicar renovación manual.

### 6. Una API para Web y Mobile

Web / React Native → API FastAPI → aplicación y dominio → PostgreSQL/PostGIS. Puertos para cobros, mapas, archivos y avisos; worker para tareas recuperables.

**Apoyo:** Abrir arquitectura y explicar las transacciones compartidas.

### 7. Condiciones que se conservan

68 RF · 19 RNF · 25 CU · 58 tablas. La aceptación conserva precio, cantidad, moneda y plazo; los reintentos recuperan la misma intención.

**Apoyo:** Abrir modelo lógico y la versión de condiciones aceptadas.

### 8. Privacidad durante el recorrido

Zona pública aproximada, archivos privados, descargas temporales y conversación de participantes. Portfolio y catálogo muestran medios autorizados. Las intervenciones administrativas conservan motivo y auditoría.

**Apoyo:** Explicar pertenencia, finalidades de archivos y límites de acceso.

### 9. Cómo evaluamos el producto

161 escenarios de cobertura, 29 fichas detalladas y ocho ensayos no funcionales. PERF-01 define datos, carga, accesibilidad, integridad y recuperación. Cada ejecución conserva release y evidencia.

**Apoyo:** Mostrar una ficha y un resultado real cuando exista la ejecución del release.

### 10. El próximo avance

Base y perfiles → solicitud y catálogo → pedidos y abono → revisión y entrega → pruebas y release. Documentación, manuales y trazabilidad acompañan cada iteración.

**Apoyo:** Cerrar con el paquete y los siguientes hitos del cronograma.

## Guion de demostración

[Recorrido y preparación de la demo](/3daltoque-docs/presentacion/demo/). El registro de una demostración conserva release, entorno, actores y resultado por paso. El tiempo de exposición y el formato del video se ajustan a lo comunicado por la cátedra.
